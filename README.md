# DocAtsu

Desktop Application for Project & Document Management.

Manage projects, WBS, tasks, milestones, Gantt charts, documents, and PDF files in one workspace.

### Download

Download the latest Windows and macOS installers from [GitHub Releases](https://github.com/nuengfiew-max/DocAtsu-Downloads/releases).

**Supported Platforms**
- Windows (x64)
- macOS 15+ (Apple Silicon / Intel)
